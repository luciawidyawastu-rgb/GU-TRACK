# GU-TRACK
GU Track adalah platform web untuk memantau perjalanan keluhan genitourinari (GU) melalui check-in gejala interaktif, timeline, dan grafik perkembangan. Pengguna dapat mengunduh Consultation Snapshot PDF untuk konsultasi dokter. Staf klinik dapat mengelola pasien, jadwal, dan statistik. Tersedia dalam Bahasa Indonesia dan Bahasa Inggris.
